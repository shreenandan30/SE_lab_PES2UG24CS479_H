# Lab 4 — Flappy Bird

This folder contains the Lab 4 Flappy Bird code and supporting material copied from the original repository.

## Contents

- `main.py` and `Code/main.py` — game entry points.
- `Code/game_engine.py` — game engine.
- `game/bird.py` and `game/pipe.py` — game components.
- `Code/sounds/` — sound effects.
- `requirements.txt` — Python dependency list.
- `Chat_History.pdf` — lab chat history.
